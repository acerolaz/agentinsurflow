# Fiche du modèle glm-freq-20261028-v1

GLM de Poisson de **fréquence annuelle de sinistres** (compétence C12). **Comparaison seulement** :
la fréquence n'entre jamais dans la décision, la prime ni le rapport de l'Actuaire.

## Variables
- **Utilisées** : `BonusMalus` (= `crm` × 100, en `log`, borné à [50, 230]),
  `VehPower` (= `puissance_fiscale_cv`, bornée à [4, 12], modalités >= 12 regroupées,
  indicatrices, référence 4), `Region` (département → ancienne région,
  22 indicatrices, référence R11).
- **Exclues** : `DrivAge`, `VehAge`, `VehBrand`, `VehGas`, `Area`, `Density`. Le modèle est
  volontairement limité aux trois variables que le profil de l'API porte déjà, pour rester
  comparable au barème ; les autres ne sont pas dans le contrat d'entrée.

## Exposition
`PoissonRegressor` sur `y = ClaimNb / Exposure` avec `sample_weight = Exposure` est **équivalent
exact** du GLM log-Poisson avec offset `log(Exposure)`. `Exposure` est plafonnée à 1, `ClaimNb` à 4.

## Hyperparamètre
`alpha` = 0.0001 (régularisation L2 faible, fixée d'avance, non ajustée sur le test).

## Limites
Trois variables seulement ; jeu français historique (freMTPL2) ; entrées hors bornes **bornées**,
jamais extrapolées ; départements d'outre-mer hors modèle. Usage : comparaison avec le barème,
jamais décision ni tarification.

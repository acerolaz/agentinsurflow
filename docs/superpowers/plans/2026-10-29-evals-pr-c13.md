# evals-pr contre staging, rapport sur la PR (#55, C13) — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** réactiver le job `evals-pr` de `ci-cd.yml` : test des données, golden set et jeu de démo de la PR rejoués contre staging, rapport en artefact et en commentaire de PR, déclenchable par libellé `evals` et `workflow_dispatch`, documenté.

**Architecture :** trois briques. (1) `tools/donnees_evals.py`, test des données hors réseau, lancé par `uv` car il réutilise `lire_instantane` de `rag` ; (2) `tools/evals.py` gagne `--resume` (résumé Markdown du rapport), en restant stdlib seule (le job `changements` l'importe avec `python3` nu) ; (3) le job `evals-pr` enchaîne les deux et poste le résumé. Doc dans `docs/ci-evals.md`.

**Tech stack :** GitHub Actions, `azure/login` OIDC, `gh` CLI, Python 3.12 (stdlib + `agentinsurflow_rag`), pytest, PyYAML (déjà en dev).

**Spec :** `docs/superpowers/specs/2026-10-29-evals-pr-c13-design.md`

## Global Constraints

- Aucun secret ; aucune écriture Azure ou Entra ; sujets OIDC utilisés : `pull_request` et `ref:refs/heads/main` seulement.
- `tools/evals.py` reste **stdlib seule** (importé par `python3` nu dans le job `changements`).
- Le jeton (`EVALS_JETON`) n'apparaît ni dans un log, ni dans le rapport, ni dans le commentaire.
- Le commentaire et la doc disent la limite : jeux d'évaluation de la PR, code de `main` servi par staging ; prompt de la PR évalué après merge seulement (job `evals`).
- Français partout ; tests nommés `test_<comportement>`, docstring de module qui donne le niveau (TU/TI), comme `tests/unit/test_ci_modele.py`.
- Le job `evals` de staging et la chaîne de merge ne changent pas.
- `make test` et `make lint` passent à chaque commit.

## Review Focus

1. **Staging injoignable ou `evals.py` en échec avant d'écrire le rapport** : le commentaire est quand même posté (« rapport absent, voir le run ») et le job échoue. → Task 3, test `test_commentaire_meme_sans_rapport`.
2. **`STAGING_URL` vide** : échec immédiat, message `::error::` explicite, avant tout appel. → Task 3, test `test_staging_url_exigee`.
3. **Deux instantanés dans `data/raw/`** : seul le plus récent par nom (celui qu'ingère `deploy.yml`) est contrôlé. → Task 1, test `test_dernier_instantane_par_nom`.
4. **Article attendu écrit « L. 211-1 »** : normalisé comme `evals._article` avant comparaison, pas d'échec à tort. → Task 1, test `test_article_normalise_avant_comparaison`.
5. **Cas écartés par `--sans-dossiers`** : listés dans le résumé, pour que le jury ne croie pas qu'ils ont réussi. → Task 2, test `test_resume_liste_les_ecartes`.

### Task 1 : test des données (`tools/donnees_evals.py`)

**Files :**

**Interfaces :**
- Consumes : `agentinsurflow_rag.cli.ingest.lire_instantane(chemin: Path) -> tuple[list[dict], str, date]` (lève `ErreurEnvoi` si sha256 ≠ manifeste) ; `tools.evals._article(numero: str) -> str`.
- Produces :
  - `controler_cas(lignes: list[str], fichier: str) -> list[str]` — messages d'erreur, liste vide si conforme.
  - `articles_manquants(cas: list[dict[str, Any]], connus: set[str]) -> list[str]` — un message par article attendu absent.
  - `dernier_instantane(dossier: Path) -> Path` — `sorted(dossier.glob("code-assurances-*.json"))[-1]`.
  - `main(argv: list[str] | None = None) -> int` — options `--golden` (défaut `eval/golden.jsonl`), `--questions` (défaut `eval/questions-demo.jsonl`), `--instantanes` (défaut `data/raw`) ; affiche le sha256 de chaque fichier contrôlé ; 0 si tout passe, 1 sinon, chaque erreur sur sa ligne préfixée `✘`.
  - Lancement : `uv run python -m tools.donnees_evals` (cible `make donnees-evals`).

Règles de `controler_cas` (lignes vides ignorées, comme `evals._jsonl`) : JSON valide ; `id` chaîne non vide et unique dans le fichier ; `question` chaîne non vide ; clés de premier niveau ⊂ `{id, question, attendu, numero_contrat, ci}` ; `attendu` dict dont les clés ⊂ `{statut, articles, http}` ; `statut` ∈ `{"OK", "NOT_FOUND_IN_CORPUS"}` s'il est présent ; `articles` liste de chaînes ; `http` entier. Message : `"{fichier}:{n° de ligne} {raison}"`.

Contrôle d'intégrité dans `main` : `lire_instantane` (sha256) **et** `len(articles) == manifeste["articles"]` ; `ErreurEnvoi` attrapée et rendue en message, pas en trace.
